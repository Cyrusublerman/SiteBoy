DISTORT is a composable image-effect pipeline tool. The user builds a stack of effect nodes — drawn from a library of 69 modules across 21 categories — and processes a source image through them in order. Each node in the stack applies one deterministic transformation: a colour grade, a blur, an edge detection, a warp, a generative texture, or a physics simulation. The results compose: a Gaussian blur followed by a Sobel edge detector followed by a colour grade is a different effect from the same three nodes in any other order.

The tool's architecture separates concerns across three layers. The *host* provides the persistent UI shell (top bar, sidebar, canvas viewport, transport strip) and manages application state, routing, and export. The *pipeline engine* (off-thread in a Worker) accepts a stack specification, allocates buffers, executes each node's `apply()` method in order, and returns the composited result. The *module library* consists of 69 self-contained effect modules, each exposing a single `apply(src, dst, w, h, params, ctx, modulate)` function plus optional vector-output (`buildGeometry`) and animation (`buildAnimFrame`) methods.

The execution model is dual-quality: a PREVIEW path (max 800px, fast) serves interactive feedback; a FULL path (source resolution) is triggered for export. All interactive parameter changes enqueue a PREVIEW render; the queue accepts only one pending PREVIEW request at a time, so rapid slider changes produce only one completed render. The pipeline is cached at the node level: a node whose parameters and upstream input have not changed returns its cached output buffer without re-executing `apply()`. The LRU cache ceiling is 128 MB.

GPU compute acceleration is available for eligible modules. The GPU tier is determined at startup by testing `navigator.gpu` (WebGPU) and `getContext('webgl2')` (WebGL2). Eligible modules can dispatch compute shaders for per-pixel operations, falling back to CPU when the GPU tier is insufficient. See *GPU Compute* for the full tier matrix.
