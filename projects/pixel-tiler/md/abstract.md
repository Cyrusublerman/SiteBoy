Pixel Tiler takes four source images and constructs a single output image by interleaving their pixels in a fixed 2×2 tile pattern: each output pixel of position \((x, y)\) draws its value from image A (top-left), B (top-right), C (bottom-left), or D (bottom-right) based on the parity of \(x\) and \(y\). The mapping doubles the image dimensions while creating a spatial weave that, at viewing distance, reads as a composite of all four sources.

The tool's second capability is combinatorial enumeration. Rather than fixing A, B, C, D to the four slots, it can generate the full set of orderings: the 24 distinct permutations of four images across four slots, or the 256 arrangements that result when each of the four positions independently draws from any of the four images with repetition. Both sets are rendered as an indexed frame sequence and played back as an animation, allowing the user to sweep through the entire combinatorial space or export any subset.

This makes Pixel Tiler useful both as a compositing tool (select one arrangement, export a PNG) and as a generative survey instrument: stepping through 256 frames reveals how spatial frequency, contrast, and colour balance interact across the full permutation space of a given source set. The GIF export path encodes the animation directly at the displayed frame rate for use in other contexts.
