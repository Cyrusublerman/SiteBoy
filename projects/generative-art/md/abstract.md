The generative art collection is a set of interactive mathematical visualisations, each rendering a continuous dynamical system or parametric surface in real time on an HTML5 canvas. The unifying principle across all pieces is that every visual element is computed deterministically from a small number of parameters — there is no pixel-level randomness in the core output. Any visual diversity arises from the structure of the underlying mathematics: resonance in Lissajous frequency ratios, interference in wave superpositions, the golden angle in phyllotactic spirals, and grid-state transitions in cellular automata.

Each piece lives on the unified Generator Host (`#tools/generators`), which provides a standardised four-tab sidebar (PARAMS, ANIMATE, EXPORT, INFO) and a canvas managed by `AnimationFoundation.AnimationLoop`. The host abstracts frame timing and parameter change detection so that each generator focuses purely on its mathematical content. All animation is frame-indexed (deterministic: frame \(n\) always produces the same output given the same parameter state), and all exports are derived from that same deterministic frame function.

The pieces span five mathematical families: parametric curves (Lissajous, Harmonics, Spirals), wave patterns (Cymatics, Wave Interference, Wave Equation Synth), phyllotactic geometry (Phyllo Spiral, Spinning Phyllo Ball, Phyllo Plane, Spiral N-gon 3D), geometric and grid patterns (Squares, Nested Circles, Torus, Clock, Colour Square), and optical illusions and Moiré patterns (Moiré Generator, Interference Figure). Together they form a library of mathematical visualisation techniques applicable to both aesthetic and educational ends.
