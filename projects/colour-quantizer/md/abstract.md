Colour Quantizer is the site's perceptual palette-reduction engine: a deterministic image pipeline that maps every pixel in an uploaded image to its nearest entry in a target palette using Euclidean distance in CIELAB colour space (Delta E 76), with an optional spatial dithering stage to suppress the banding that hard nearest-colour mapping produces.

The central design decision is to perform all matching in a *perceptually uniform* space rather than in sRGB or linear RGB. sRGB distance is fast but correlates poorly with how humans perceive colour difference — two colours that are numerically close in RGB can look strikingly different, and vice versa. CIELAB (CIE 1976 L\*a\*b\*) is designed so that equal numerical steps in \(L^*, a^*, b^*\) correspond to roughly equal perceived steps, making Euclidean distance a reliable proxy for visual dissimilarity.

The full processing chain is: sRGB byte values → gamma-correct sRGB → linearise (remove gamma) → XYZ (D65 illuminant) → CIELAB → nearest-palette LAB lookup → optional dither → sRGB output pixel. All intermediate values are computed in floating-point to preserve accuracy. Pre-processing adjustments (gamma, contrast, saturation) are applied *before* the LAB conversion so they operate on linear light values.

The tool ships with nine preset palettes spanning 2 to 56 colours (1-bit monochrome through the hand-curated GGost palette) and allows arbitrary custom palettes via a colour picker. Blue-noise dithering uses a pre-loaded 512×512 LDR texture; the implementation uses a *nearest/opposite* mix strategy rather than error diffusion so that it can operate pixel-independently and in any scan order.
