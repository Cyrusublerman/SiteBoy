# Docs Restructure Rationale

- **Purpose:** Make AI/maintainer navigation deterministic, minimize tokens, kill duplication/hallucination.
- **Rule:** When a file is opened, read the whole file unless a checklist says otherwise.
- **Shape:** Indices → Phases → Checklists → Standards → Catalogs → Outputs.
- **Anti-ambiguity:** Short files, fixed sections, YES/NO gates, explicit inputs/outputs.
- **Archival:** Any replaced/duplicated doc moves to `blog/docs/old-docs/` with a pointer note.
