## Implementation

### Step 1: Add manifest cache to art section

```javascript
// Add to ArtSection object
manifestCache: new Map(),

async fetchManifest(galleryName) {
    if (this.manifestCache.has(galleryName)) {
        return this.manifestCache.get(galleryName);
    }
    
    try {
        const manifest = await R2Helper.fetchGalleryManifest(galleryName);
        this.manifestCache.set(galleryName, manifest);
        return manifest;
    } catch (error) {
        console.warn(`Failed to fetch manifest for ${galleryName}:`, error);
        return null;
    }
},
```

### Step 2: Update getPhotographyImages

Replace hardcoded logic:

```javascript
async getPhotographyImages(photoSection) {
    const sectionMap = {
        'life1': 'life1',
        'life2': 'life2',
        'morocco': 'morocco',
        'nature': 'nature',
        'rom': 'rom',
        'snow': 'snow',
        'urban': 'urban'
    };
    
    if (photoSection === 'all') {
        // Fetch all manifests and combine
        const allImages = [];
        for (const galleryName of Object.values(sectionMap)) {
            const manifest = await this.fetchManifest(galleryName);
            if (manifest && manifest.images) {
                allImages.push(...this.manifestToImages(manifest, galleryName));
            }
        }
        return allImages;
    }
    
    const galleryName = sectionMap[photoSection];
    if (!galleryName) return [];
    
    const manifest = await this.fetchManifest(galleryName);
    if (!manifest) return [];
    
    return this.manifestToImages(manifest, galleryName);
},

manifestToImages(manifest, galleryName) {
    const capitalizedName = galleryName.charAt(0).toUpperCase() + galleryName.slice(1);
    
    return manifest.images.map(img => ({
        thumb: img.urls.thumb,
        src: img.urls.web,
        zoom: img.urls.zoom,
        title: `${capitalizedName} - ${img.id}`,
        caption: `Film photography from ${capitalizedName} collection`
    }));
}
```

### Step 3: Update callers to be async

`renderPhotographyGallery` currently calls `getPhotographyImages` synchronously:

```javascript
// Current (sync)
const images = this.getPhotographyImages(photoSection);

// Updated (async)
const images = await this.getPhotographyImages(photoSection);
```

The render function is already async-capable (it uses `async handleRoute`).

## Fallback

If manifest fetch fails, fall back to hardcoded lists temporarily:

```javascript
async getPhotographyImages(photoSection) {
    const manifest = await this.fetchManifest(galleryName);
    
    if (manifest && manifest.images) {
        return this.manifestToImages(manifest, galleryName);
    }
    
    // Fallback to hardcoded (until all manifests verified)
    console.warn(`Using hardcoded fallback for ${galleryName}`);
    return this.getHardcodedImages(galleryName);
},
```
