## Intended Design (per spec)

Generative Pattern is a unified pattern system for Truchet tilings, blob/inflated-union fields, and nested-contour patterns derived from a proximity graph of distributed points. The algorithm operates in four phases:

**Phase 1 — Point Distribution:** A hybrid point set is generated by blending a regular grid, Poisson-disk jitter, and noise-based cluster modulation. `density` controls point count; `gridStrength` biases toward regularity; `jitter` adds random displacement.

**Phase 2 — Graph Construction:** A proximity graph is built from the point set. Each point connects to neighbours within `connectionRadius`, with maximum degree `maxDegree`. An `axisBias` parameter weights connections toward axis-aligned directions. An `arcQuantisation` parameter quantises connection angles to discrete steps (for Truchet-compatible geometry).

**Phase 3 — Reaction-Diffusion Evolution (optional):** When `iterations > 0`, a Gray-Scott reaction-diffusion solver evolves a scalar field `(u, v)` over the point graph. Parameters `Du`, `Dv`, `feedRate`, `killRate` control the Gray-Scott dynamics. This produces organic Turing-like patterns on the graph topology.

**Phase 4 — Rendering:** A distance transform of the graph curves produces an SDF field. The SDF is rendered in one of four modes:
- `Truchet`: Template-matched arc tiles using discrete SDF thresholds.
- `Blob`: Inflated union of point weights, producing smooth blobby shapes.
- `Nested Contours`: Iso-line extraction from the SDF at `tileWindowSize`-spaced levels.
- `Global Contours`: Global iso-line extraction across the full canvas.

Animation is achieved by advecting the flow field with time (`flowSpeed`, `noiseFrequency`).

## Algorithm Sources

- Gray-Scott reaction-diffusion: Pearson (1993) taxonomy.
- Jump Flood Algorithm (JFA) for distance transform: Rong & Tan (2006).
- Truchet tiles: Smith (1987) / Browne (2008).
