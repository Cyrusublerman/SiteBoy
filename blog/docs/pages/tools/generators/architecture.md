# Generator Docs Architecture

## Layers

1. root authorities in this folder
2. process guides in `guides/`
3. reusable templates in `template/`
4. one current pack per generator
5. local archive inputs in `reference/generators/`

## Required Pack Files

- `source-reference.md`
- `description.md`
- `mechanisms.md`
- `ui-layout.md`
- `performance.md`
- `feature-parity.md`
- `issues-and-conflicts.md`
- `migration-log.md`
