# Module Template Pack

Mandatory files in every module documentation pack:

- `source-reference.template.md`
- `description.template.md`
- `mechanisms.template.md`
- `ui-layout.template.md`
- `performance.template.md`
- `feature-parity.template.md`
- `issues-and-conflicts.template.md`
- `migration-log.template.md`
- `module-pack-checklist.md`
- `module-processing-checklist.md`
- `new-feature-escalation-checklist.md`

Use `document-module.md` as the step-by-step guide. These templates define the required sections — fill every placeholder before considering a file complete.
