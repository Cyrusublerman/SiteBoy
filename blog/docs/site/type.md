# SiteBoy Typography

Summary only.

Authority:
- `blog/docs/guides/standards/design-law.md`

Typography law:
- Family: `Space Mono`
- Structural UI: `UPPERCASE`
- Block and section titles: `Title Case`
- Prose: `Sentence case`
- Quiet status text: `lowercase` only when intentionally secondary

Typography is structural, not decorative. If typography appears to solve a problem that partition, boundary, or inversion should solve, the design is wrong.
