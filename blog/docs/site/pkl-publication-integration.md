# PKL Publication Integration

## Ownership

SiteBoy renders a public snapshot generated by the private Personal Knowledge Library. SiteBoy does not read the private repository and generated PKL files are not editable source content.

## Generated location

```text
public/generated/pkl/
├── manifest.json
├── public-graph.json
├── objects/
└── revisions/
```

Vite copies `public/` into the production output. The PKL snapshot is therefore available at `/generated/pkl/` without bundling the graph into JavaScript.

## Build validation

`npm run build` runs `scripts/pkl/validate-public-graph.mjs` first. The validator checks:

- schema version;
- manifest and graph digest agreement;
- recomputed graph digest;
- manifest object count;
- required object fields;
- unique UIDs and routes;
- valid current public revisions;
- route-index integrity.

A failed snapshot blocks the SiteBoy build.

## Browser access

`assets/js/shared/pkl-content-provider.js` supplies the public content interface:

```js
import { pklContentProvider } from '/assets/js/shared/pkl-content-provider.js';

await pklContentProvider.load();
const page = pklContentProvider.getByRoute('/wiki/example');
const results = pklContentProvider.search('example', { objectType: 'concept' });
```

The provider validates the snapshot digest in the browser before indexing it. It provides UID, route, relationship, backlink, filter and text-search access without exposing private PKL metadata.

## Synchronisation

The private Library GitHub Actions workflow:

1. validates and compiles Library content;
2. checks out SiteBoy using a token stored only in Library;
3. updates `public/generated/pkl/`;
4. preserves immutable object revision files;
5. commits the changed generated directory to SiteBoy `main`;
6. allows the existing Vercel Git integration to deploy the commit.

SiteBoy contains no Library access token and cannot fetch private source material.

## Routing

The generated graph uses normal public routes:

```text
/wiki/<slug>
/blog/<slug>
/figures/<figure-uid>
```

The existing SiteBoy router remains unchanged until the Wiki and Blog section controllers consume the provider. Route migration must preserve redirects from older hash routes.

## Figure dependencies

Figure libraries are adapter dependencies, not global framework dependencies. Vega-Lite, Cytoscape.js, ELK and Observable Plot should be dynamically imported only by figure types that require them. SiteBoy SVG remains the default editorial renderer.

## Do not edit generated output

Manual changes under `public/generated/pkl/` will be replaced by the next successful Library synchronisation. Corrections belong in PKL or in the compiler and rendering systems.
