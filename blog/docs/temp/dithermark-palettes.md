## Summary

Dithermark includes **30 predefined artistic palettes**, each with **18 colours**. All palettes are designed for vibrant, stylized colour quantization effects.

### Characteristics
- **18 colours per palette** (standard)
- **6-digit hex format** (e.g. `#ab12cd`, not `#abc`)
- **Padded with `#000000`** if fewer than minimum required colours
- **Custom palette slot** (user-defined colours)
- **Saved palette system** (user can save custom palettes)

## System Features

### Custom Palette Slot
```javascript
{ title: '---', isCustom: true }
```
- First entry in array
- User can add their own colours
- No predefined colours

### Saved Palette System
```javascript
generateUserSavedPalette(colors, savedPaletteId) {
    return {
        title: `Saved Palette ${savedPaletteId}`,
        colors: colors,
        isSaved: true
    };
}
```
- Users can save custom palettes
- Persisted across sessions
- Numbered for identification

### Automatic Padding
```javascript
padPaletteColorsToMinimumLength(palettes, minimumColorsLength)
```
- If palette has fewer than minimum colours, it's padded with `#000000`
- Ensures consistent array lengths for processing

## Recommendations for SiteBoy Integration

### Option 1: Add All Dithermark Palettes
**Pros:** Massive variety, artistic options  
**Cons:** Dropdown becomes very long (40 total palettes)

### Option 2: Curated Subset (10-15 palettes)
**Recommended palettes to add:**
1. **Monochrome** - Essential grayscale
2. **Sepia** - Vintage photography
3. **Ocean** - Blue/teal theme
4. **Wildfire** - Warm/fire theme
5. **Galaxy** - Space/cosmic theme
6. **Blueberry** - Cool blues
7. **Rose** - Warm pinks
8. **Neon** - Bright/vibrant
9. **Crystals** - Jewel tones
10. **Primaries** - Bold contrast

**Pros:** Best of both worlds  
**Cons:** Subjective selection

### Option 3: Separate Palette Categories
```javascript
['Palette Category', [
    ['dropdown', 'Type', ['Technical', 'Artistic'], { key: 'paletteType' }],
    ['dropdown', 'Palette', dynamicPaletteList, { key: 'palette' }]
]]
```
- Technical: Current 9 (1-bit, NES, etc.)
- Artistic: Dithermark's 30

**Pros:** Organized, no clutter  
**Cons:** Extra click for users

## Notes

- All palettes use **6-digit hex** (`#abcdef` not `#abc`)
- Colours are **not sorted** - order is intentional for UI display
- Many palettes are **thematic** (named after moods/elements)
- **Monochrome** is the only pure grayscale
- **Mondrianchromatic** mixes grayscale + primary colours (Mondrian art style)
- Dithermark allows **unlimited custom colours** in custom palette
- SiteBoy currently limits custom palette to ~20 colours (UI constraint)
