# Component Process

1) Reuse check: read `components/index.md` + `COMPONENT-REFERENCE.md`; scan code exports.
2) Choose category: input/output/container/tool.
3) Implement in category folder; extend BaseComponent; follow rules/nomenclature.
4) Export chain: category index → components/index.js → component-library.js.
5) Docs: add/update `components/<category>/<Name>.md` with props/events/examples.
6) Tests/checklists: component-development checklist; F-system/color; duplication guard.
