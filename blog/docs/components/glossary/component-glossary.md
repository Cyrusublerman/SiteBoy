# Component Glossary

- NumericInput — slider/number/stepper modes.
- TextInput — text/textarea modes.
- Dropdown — select menu.
- ToggleGroup — checkbox/radio group.
- Button — action button.
- FileInput — file picker.
- ColorInput — color picker.
- EquationEditor — interactive equation params.
- Text — heading/body/status/value display.
- ProgressBar — determinate/indeterminate progress.
- Canvas — ToolBase canvas access.
- SVG — vector container.
- Media — image/video/audio display.
- AudioOutput — Web Audio output.
- Stack — row/column flex stack.
- Grid — N×M layout.
- Section — titled/collapsible group.
- Tabs — tabbed container.
- Collection — list/grid items.
- NavigationDropdown — tool nav dropdown.
- CanvasTabs — canvas tab switcher.
