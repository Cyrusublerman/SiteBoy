# Component Nomenclature

- Classes: PascalCase; files match class.
- componentType (factory strings): lower-kebab (e.g., `stack`, `tool-numeric-input`).
- Keys: camelCase; tabs UPPERCASE; blocks Title Case.
- Options: label/key/value/onChange/onInput; follow existing component patterns.
- Events: onChange (commit), onInput (live) where applicable.
