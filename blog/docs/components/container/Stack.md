# Stack

Row/column flex stack.

## Options
- `direction` ('row'|'column', default 'column')
- `gap` (number in F units, default 1)
- `align` ('start'|'center'|'end'|'stretch', default 'stretch')
- `padding` (F units, default 0)
- `children` (array of components/elements)

## Methods
- `addChild(child)`
- `clear()`

## Notes
- Full-width; uses F for spacing.
