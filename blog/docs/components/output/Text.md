# Text

Heading/body/status/value display.

## Options
- `content` (string)
- `variant` ('heading'|'body'|'status')
- `level` (1-6, for heading)
- `status` ('success'|'error'|'warning')
- `label`/`unit` when used as value display
- `key` (string, optional)

## Notes
- Use `variant: 'status'` for inline status messages.
