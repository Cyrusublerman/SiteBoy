# ProgressBar

Determinate/indeterminate progress display.

## Options
- `label` (string)
- `value` (0-100, default 0)
- `indeterminate` (bool, default false)
- `showLabel` (bool, default true)
- `key` (string, for programmatic updates)

## Methods
- `setValue(n)` to update percentage.

## Notes
- Use for render/export/loading status.
