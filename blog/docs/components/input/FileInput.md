# FileInput

File picker button.

## Options
- `label` (string)
- `accept` (string, e.g., 'image/*', '.json')
- `multiple` (bool, default false)
- `buttonText` (string, default 'Choose...')
- `key` (string, auto)
- Events: `onChange(files)` (File or FileList)

## Notes
- Uses native input; styled via component.
