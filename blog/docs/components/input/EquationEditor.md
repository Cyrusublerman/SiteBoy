# EquationEditor

Interactive equation with editable params.

## Options
- `template` (string, uses `{var}` placeholders)
- `params` (object: each `{ value, min, max, step, precision }`)
- `key` (string, auto)
- Events: `onChange(params)`

## Notes
- Value: object of param values.
- Use for parametric equations (Lissajous, harmonics, etc.).
