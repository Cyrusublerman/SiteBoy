# ToggleGroup

Checkbox/radio group.

## Modes
- `mode: 'checkbox'` (default, multi-select)
- `mode: 'radio'` (single-select)

## Options
- `label` (string)
- `items` (array of labels)
- `mode` ('checkbox'|'radio')
- `layout` ('list'|'row')
- `key` (string, auto)
- Events: `onChange(values)` (array for checkbox, string for radio)

## Notes
- Aliases: `toggle`, `radio`.
