#### 1. Basic Triads

- **Major (Maj)**
    - **Symbol:** M or omitted
    - **Steps:** 0, 4, 7
- **Minor (Min)**
    - **Symbol:** m
    - **Steps:** 0, 3, 7
- **Augmented (Aug)**
    - **Symbol:** +
    - **Steps:** 0, 4, 8
- **Diminished (Dim)**
    - **Symbol:** °
    - **Steps:** 0, 3, 6

#### 2. Seventh Chords

- **Dominant Seventh**
    - **Symbol:** 7
    - **Steps:** 0, 4, 7, 10
- **Major Seventh**
    - **Symbol:** Maj7 or Δ
    - **Steps:** 0, 4, 7, 11
- **Minor Seventh**
    - **Symbol:** m7
    - **Steps:** 0, 3, 7, 10
- **Half-Diminished**
    - **Symbol:** ø
    - **Steps:** 0, 3, 6, 10
- **Diminished Seventh**
    - **Symbol:** °7
    - **Steps:** 0, 3, 6, 9

#### 3. Extended Chords

- **Ninth (9th)**
    - **Symbol:** 9
    - **Steps:** 0, 4, 7, 10, 14
- **Major Ninth**
    - **Symbol:** Maj9
    - **Steps:** 0, 4, 7, 11, 14
- **Minor Ninth**
    - **Symbol:** m9
    - **Steps:** 0, 3, 7, 10, 14
- **Eleventh (11th)**
    - **Symbol:** 11
    - **Steps:** 0, 4, 7, 10, 14, 17
- **Thirteenth (13th)**
    - **Symbol:** 13
    - **Steps:** 0, 4, 7, 10, 14, 17, 21

#### 4. Suspended Chords

- **Suspended Second**
    - **Symbol:** sus2
    - **Steps:** 0, 2, 7
- **Suspended Fourth**
    - **Symbol:** sus4
    - **Steps:** 0, 5, 7

#### 5. Altered Chords

- **Augmented Seventh**
    - **Symbol:** 7♯5 or 7+5
    - **Steps:** 0, 4, 8, 10
- **Augmented Major Seventh**
    - **Symbol:** Maj7♯5
    - **Steps:** 0, 4, 8, 11
- **Diminished Major Seventh**
    - **Symbol:** m♯7
    - **Steps:** 0, 3, 6, 11
