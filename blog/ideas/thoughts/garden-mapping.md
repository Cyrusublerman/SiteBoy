# Garden Mapping
**Status:** STUB


Use a drone to produce an accurate top-down map of the garden. Potentially extend to a 3D model via photogrammetry.

## Possible outputs

- Orthographic 2D map for planning planting layouts.
- 3D point cloud or mesh for elevation and structure analysis.

## Tools to investigate

- Photogrammetry: Meshroom, RealityCapture, DJI Terra.
- Drone options: anything with a nadir (straight-down) camera mode.
