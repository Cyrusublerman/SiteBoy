## 1. Purpose and Scope
This document defines the full design plan for a unified generative system capable of producing all provided mid‑century geometric motifs (Googie, Atomic Age, and Op‑Art derivatives) (loose overlapping shapes, strict grids, nested squares, concentric 70s motifs) using one continuous algorithm. All outputs emerge from one equation family and a small set of continuous parameters. No mode switching, blending, or flow branching is required.

This design adheres to the Site Pages documentation framework: strict modularity, scalar parameterisation, systemic logic, and formal mathematical grounding.

---

## 2. Conceptual Framework
The system relies on a single implicit geometric primitive (a superellipse-based Googie-rectangle primitive) placed on a warped grid. All stylistic variability — rigid vs chaotic, rounded vs square, nested vs flat, merged vs separate — arises from continuous parameter adjustments.

### 2.1 Underlying Principle
Every motif is generated by the implicit function:

```
f_k(x) = ( |u_x / a_k|^p + |u_y / b_k|^p )^(1/p) - 1
```

where `u = W(x) - c_k` and `W(x)` is a global coordinate warp.

### 2.2 Core Abstractions
- **Grid Module**: defines positions c_k via cell coordinates, jitter, and density fields.
- **Googie‑Shape Module**: superellipse geometry with parameters controlling anisotropy, rounding, and scale.
- **Atomic Warp Module**: smooth global coordinate distortion for hand-drawn irregularity.
- **Nesting Module**: scaled repetitions of the base shape within the same cell.
- **Op‑Art Blend Module**: smooth-union of shapes sharing a class/label to create merged boundary behaviours.
- **Styling Module**: independent colour palette mapping, stroke ordering, and compositing.

## 3. Layout System
This section defines the spatial logic controlling distribution, alignment, and deformation.

### 3.1 Grid Structure
- Logical grid: integer index space `(i, j)`.
- Cell spacing: `(s_x, s_y)`.
- Base centres: `c_ij = (i*s_x, j*s_y)`.
- Jitter: random or noise-based offsets scaled by jitter parameter `J ∈ [0,1]`.
- Density/occupancy: scalar field `D(i,j)` determining shape presence and size.

### 3.2 Warp Transformation
A smooth deformation field `W(x)` controls outline looseness.

Parameters:
- **Warp amplitude A_warp**
- **Warp frequency ω**
- **Noise field φ** controlling direction and curvature

### 3.3 Layering and Depth
- Each shape receives a continuous depth index `z_k`.
- Rendering uses z-sorted passes for fills and outlines.

## 4. Modular Components
Each module exposes inputs/outputs and remains reusable across pages and other algorithms.

### 4.1 Grid Module
**Inputs**:
- Scalar cell spacing
- Jitter parameter
- Density field parameters

**Outputs**:
- Set of centres `c_k`
- Per-shape meta-parameters (size, rotation offset, nesting count)

### 4.2 Shape Module
**Inputs**:
- Centre position c_k
- Half-widths a_k, b_k
- Corner exponent p_k
- Scale factor for nesting l-levels

**Outputs**:
- Implicit field value f_k(x)

### 4.3 Warp Module
**Inputs**:
- Warp amplitude A_warp
- Frequency and phase
- Noise/analytic basis functions

**Outputs**:
- Warp transform W(x)

### 4.4 Blend Module
**Inputs**:
- Set of fields f_k for label g(k)
- Blend radius σ

**Outputs**:
- Smooth-union field F_c(x) representing merged shapes of a single colour region

### 4.5 Style Module
**Inputs**:
- Region label c
- Tone or greyscale seed
- Palette mapping function

**Outputs**:
- Final colour for each pixel or vector object

## 5. Parameter Schema
A single vector P controls all behaviour:

```
P = {
  grid_spacing,
  jitter_J,
  warp_amplitude_A,
  warp_frequency_ω,
  rounding_p,
  aspect_ratio_range,
  size_distribution,
  nesting_L,
  nesting_ratio_r,
  blend_radius_σ,
  density_field_params,
  palette_params
}
```

Different pattern families arise from shifts in P:
- **Structured retro**: J≈0, A≈0, p→∞, L≥2
- **Soft blobs**: p≈2–4, smooth palettes
- **Chaotic overlaps**: high J, high A, mixed p, broad aspect ratios
- **Quilt-like regular**: J=0, A=0, p large, discrete size set

All changes remain continuous.

## 6. Behavioural Modes via Continuous Adjustment

### 6.1 Regular ↔ Chaotic Layout
Transition by modulating jitter and density.

### 6.2 Rounded ↔ Hard Geometry
Corner exponent p controls the circle–square continuum.

### 6.3 Concentric ↔ Single-Level
Nesting depth L and scale ratio r regulate multilevel box patterns.

### 6.4 Fused ↔ Separate Shapes
Blend radius σ determines if same-colour areas merge.

### 6.5 Warped ↔ Orthogonal
Warp amplitude A controls hand-drawn variation.
